# 🎵 Music Player

A modern and responsive **Music Player Web Application** designed with a clean interface and intuitive controls for a smooth music-listening experience.

## ✨ Features

🎧 **Play / Pause** — Easily control music playback.
⏮️ **Previous / Next** — Navigate between tracks.
📊 **Progress Bar** — Track and control the current playback position.
🔊 **Volume Control** — Adjust audio volume seamlessly.
🎶 **Song Information** — Display track title and artist details.
📱 **Responsive Design** — Optimized for different screen sizes.
⚡ **Interactive UI** — Smooth and user-friendly controls.

## 🛠️ Technologies Used

* 🌐 **HTML5** — Structure and semantic markup
* 🎨 **CSS3** — Styling, layout, and responsive design
* ⚙️ **JavaScript** — Music playback and interactive functionality

